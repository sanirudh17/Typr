Commands

Voice commands you can speak while dictating

How voice commands work
Speak a command as part of the same dictation — e.g. say “camel case get user by id” or “we meet monday scratch that we meet tuesday” in one breath. They're applied deterministically before the text is pasted, work offline, and run whether AI Cleanup is on or off. Editing commands only affect the current dictation — not text you've already pasted.

Code casing

“camel case get user by id”→getUserById
“pascal case user service”→UserService
“snake case max retry count”→max_retry_count
“constant case max buffer size”→MAX_BUFFER_SIZE
“kebab case main nav bar”→main-nav-bar

Layout & symbols

“new line” / “new paragraph”→line / blank-line break
“new bullet buy milk”→- buy milk
“space bar”→(a literal space)
“semicolon”→;
“open/close paren” (or “parenthesis”)→( )
“open/close brace / bracket / angle”→{ } [ ] < >
“hyphen”→-

Editing (within the same dictation)

“scratch that” / “strike that”→erase the last sentence
“scratch all”→erase everything so far
“delete last word”→remove the last word
“capitalize that”→Capitalize the last word
“uppercase that” / “all caps that”→UPPERCASE the last word
“lowercase that”→lowercase the last word
“milk, eggs and bread make it a list”→bulleted list

Dictionary

Manage custom spelling hints for the AI transcription engine.

What are Spelling Hints?
Hints are a recognition aid: your terms (e.g. Tauri, IBM Plex, agentic) are sent to the transcription engine so it's more likely to hear and spell them correctly. They only nudge the engine — they never rewrite your text, so everyday words are never mangled.

Need a term to always come out a specific way, or a shortcut expanded? Use the Snippets tab. Smarter, context-aware fixes (e.g. knowing CAT the exam from cat the animal) are coming with AI post-processing.

Snippets

Create post-processing text replacement snippets to correct transcription spelling errors or expand shorthand shortcuts.

What are Text Replacement Snippets?
Strict post-processing replacement rules. Whenever the transcribed text contains the snippet Find shortcut (as a separate word), it is replaced by the Replace With snippet text. Excellent for fixing consistent AI spelling errors (e.g. tory → Tauri) or expanding short text shortcuts (e.g. brb → be right back, my email → user@example.com). Non-alphanumeric shortcuts (like :) → 😊) work too!
