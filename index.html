AI

Optional AI cleanup of your transcripts

AI Post-Processing
Sends your transcript to Groq for a cleanup pass that fixes spelling, casing, punctuation, filler words, and context-based mis-hearings (e.g. write a letter vs right turn). Needs internet. If it's offline or slow, Typr falls back to standard cleanup instantly, so dictation never stalls.
AI Cleanup Off by default. Everything below applies only when this is on.

AI cleanup is off. Turn it on to choose a profile, model, and output style.

Commands

Phrases you can speak mid-dictation to format text

How voice commands work
Say the command in the same breath as your words — e.g. “camel case get user by id”, or “we meet monday scratch that we meet tuesday”. Commands work offline, run whether AI cleanup is on or off, and are applied before the text is pasted. Editing commands only affect the dictation in progress, never text you have already pasted.

Code casing

“camel case get user by id”→getUserById
“pascal case user service”→UserService
“snake case max retry count”→max_retry_count
“constant case max buffer size”→MAX_BUFFER_SIZE
“kebab case main nav bar”→main-nav-bar

Layout & symbols

“new line” / “new paragraph”→line / blank-line break
“new bullet buy milk”→- buy milk
“space bar”→(a literal space)
“semicolon”→;
“open/close paren” (or “parenthesis”)→( )
“open/close brace / bracket / angle”→{ } [ ] < >
“hyphen”→-

Editing (within the same dictation)

“scratch that” / “strike that”→erase the last sentence
“scratch all”→erase everything so far
“delete last word”→remove the last word
“capitalize that”→Capitalize the last word
“uppercase that” / “all caps that”→UPPERCASE the last word
“lowercase that”→lowercase the last word
“milk, eggs and bread make it a list”→bulleted list

Write Mode (selected text, not dictation)

Select text in any app and press your Write Mode hotkey (Recording → Hotkeys). The AI rewrite replaces the selection; Ctrl+Z undoes it. Needs AI cleanup on with a Groq key, and honours your Tone / Formatting / Custom instructions.

Select text, press Write Mode hotkey→selection rewritten in place
Nothing selected→a notice; your text is untouched
AI off or key missing→a notice asking to enable it
Rewrite fails or times out→a notice; your text is untouched
Ctrl+Z right after a rewrite→restores your original text

Dictionary

Teach the transcription engine your names and terms

How hints work
Hints are a recognition aid. Your terms — Tauri, IBM Plex, agentic — are sent to the engine so it is more likely to hear and spell them correctly. They only nudge it; they never rewrite your text, so everyday words are never mangled.

Need a term to come out a specific way every time, or a shortcut expanded? Use Snippets instead.
Add a hint A name, brand, or rare term the engine keeps getting wrong.
Active hints Sent with every transcription. Keep the list short so each term carries weight.

Snippets

Always-replace rules for fixes and shortcuts

How snippets work
Exact replacements, applied every time. When the transcript contains your Find text as a separate word, it becomes the Replace with text. Good for a misheard word that is always wrong the same way (tory → Tauri) or a shortcut worth expanding (brb → be right back, my email → user@example.com). Symbols work too: :) → 😊.

Unlike a Dictionary hint, this always fires — so pick a Find term you would never say by accident.
